ADMINISTRACIÓN EN LA NUBE

Permite gestionar recursos de TI de forma flexible, escalable y eficiente mediante plataformas y servicios basados en la nube.

En el contexto de Gerencia de Sistemas de Información, la administración en la nube es clave para optimizar procesos, reducir costos operativos y aumentar la disponibilidad de servicios tecnológicos.

1. Funciones

Incluyen la gestión de recursos virtuales, monitoreo de rendimiento, seguridad, copias de respaldo, automatización de tareas y administración de usuarios y accesos.

2. Tecnología

Se apoya en plataformas como Amazon Web Services (AWS), Microsoft Azure, y Google Cloud Platform (GCP), que ofrecen infraestructura como servicio (IaaS), plataforma como servicio (PaaS) y software como servicio (SaaS).
